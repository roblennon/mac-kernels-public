I started this because the quantized checkpoints everyone shares were built for CUDA. On a Mac with torch 2.14 or earlier, ComfyUI either decompreses every weight on every call, which is slow, or refuses the file outright. (PyTorch 2.15.0 added a generic MPS `_int_mm`; on this M1 Max it runs 7 to 8% slower than fp16 at K=6144, see the findings for November 9.) So I wrote Metal kernels that keep the packed wieghts resident in GPU memory and decode them inside the same pass that feeds a normal fp16 matrix multiply. That covers weight-only INT8 with online rotation (ConvRot), W4A8, W6A8, and the GGUF block formats. Everything is measured on one Mac Studio (M1 Max, 32 GB), and the pieces that hold up go upstream.

This repo has the benchmarks, the ComfyUI nodes and loaders, the local workbenches, the trainer, and the measurments. The kernels themselves live in patched forks of ComfyUI and comfy-kitchen (see [Kernel source](#kernel-source)).
